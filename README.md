# RepoBrief

> Pack any repo into clean LLM context, then chat with it -- using Claude, GPT, or a fully offline Ollama model. No vector DB. No GPU. One command.

**Under active development** -- see [planning/](./planning/) for the development roadmap.

## Installation (dev)

```bash
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -e ".[dev]"
```

## Running Tests

```bash
pytest
```
